# TVora visual identity

The phone interface preserves Clean Your TV's original visual system: black background,
white primary actions, Outfit typography, pill buttons, translucent glass and context glow.
The original animated TV illustration, press feedback, sheets and navigation motion remain.
TVora's additional app visibility, quick-button and photo controls use the existing list-row
and sheet components. Do not replace this visual system as part of a branding tweak.

TVora is the app name and installed identity. The current launcher icon is provisional;
logo work is deferred at the owner's request. Upstream credits and notices remain visible.
TV launcher appearance remains the chosen original coloured-glow theme.
